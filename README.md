# Project Automata

Cocos Creator 3.8.8 baseline for Project Automata.

This repository currently contains the Cocos bootstrap, pure TypeScript/config checks, and the AUT-CX-004 Android debug build baseline.

## Requirements

- Cocos Creator 3.8.8
- Android SDK Platform 36
- Android NDK 25.2.9519653 as generated by Cocos Creator 3.8.8
- TypeScript
- Standard mobile 3D project workflow

The expected local editor path is a normal Cocos Creator 3.8.8 installation. No absolute editor path is committed.

## Open The Project

Open this repository root in Cocos Dashboard or Cocos Creator 3.8.8. The startup scene is:

```text
assets/scenes/app/Main.scene
```

When the scene runs it should display:

```text
Automata
Runtime OK
```

The startup component logs exactly:

```text
AUTOMATA_RUNTIME_OK
```

## Android Debug Build

The reproducible Android baseline is:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\ci\build_android.ps1
```

The wrapper uses `C:\ProgramData\cocos\editors\Creator\3.8.8\CocosCreator.exe` by default, or `COCOS_CREATOR_EXE` when set. It generates `build/android/proj`, invokes the generated Gradle wrapper for `:ProjectAutomata:assembleDebug`, verifies a fresh non-empty debug APK, and checks arm64 native-library LOAD segment alignment for 16 KB page-size compatibility.

The expected debug APK is under:

```text
build/android/proj/build/ProjectAutomata/outputs/apk/debug/
```

The Android application ID is the documented placeholder `com.projectautomata.androidbaseline`; it is not a final production package ID.

## Directory Policy

- `assets/` contains Cocos-authored scenes, scripts, metadata, and future presentation assets.
- `data/` is reserved for future authored game configuration. AUT-CX-001 does not add gameplay data or config loading.
- `native/engine/` is reserved for project-owned native/engine source and must remain trackable.
- `build/`, `temp/`, `library/`, `local/`, editor caches, and generated native/platform output are generated and must not be committed.
- `tests/` and `tools/` contain the current pure TypeScript/config checks and Android debug build wrapper.

## Current Smoke Check

Manual runtime check in Cocos Creator 3.8.8:

1. Open the project root.
2. Open `assets/scenes/app/Main.scene`.
3. Press Preview.
4. Confirm the scene displays `Automata` and `Runtime OK`.
5. Confirm the console contains exactly `AUTOMATA_RUNTIME_OK` from `AppStartup`.
